# SYSU SNAT

`snat` 提供 OpenWrt 软件包 `sysu-snat`，维护者为 RenAhsAcme。页面位于 **服务 → SYSU SNAT**。全新安装默认禁用；启用并保存应用后立即运行并启用开机启动，禁用并应用后停止任务、取消自启动，并释放插件持有的地址、规则和路由。

## 地址与验证

- **WAN 原生地址**：来自 netifd 管理的接口配置，不以设备地址列表第一项作为依据。IPv6 的 DHCPv6 与 RA 自动配置可能共存，来源不能确定时页面明确显示自动配置。
- **WAN 主地址**：自动选择可用原生地址，或手动选择其中一个。当前在线接口不拥有手动指定的地址时，配置应用被拒绝，继续使用此前有效配置。
- **扩展地址池**：插件添加、通过地址冲突检查及绑定源地址 HTTPS 验证的地址。状态同时核对地址仍然绑定、运行标记及 NAT 表是否存在；验证时间表示最近构建的结果，不代表持续探测每个地址。
- **其他已绑定地址**：系统或其他服务维护的地址，只显示，不认领或清理。

IPv4 从私有 WAN 网段的最后一个 `/24` 中选择候选，WAN 子网更小时使用实际子网。排除网络、广播、网关、原地址、本机地址及 ARP 响应或状态不明确的地址。IPv6 在当前全球单播 `/64` 中随机生成有限候选，等待 DAD 后验证；默认 254，最大 512。

验证先通过原生地址解析一次目标，再绑定候选源地址请求 HTTPS，保留域名、SNI 和证书校验。临时同源 SNAT 防止后续 masquerade 产生假阳性。IPv6 检测到现有 OpenClash 规则时，继续检查目标的直连集合，避免代理出口被误认为候选地址可用。

ARP/DAD 不能确认离线设备的地址归属或上游分配权限。此功能只适用于允许使用额外地址的网络。验证通过也只证明验证时能够访问指定目标。

## 出口策略

分别为 IPv4、IPv6，以及 LAN 转发、代理进程组、Tailscale 转发配置 TCP、UDP、其他协议：

| 方式 | 行为 |
| --- | --- |
| 保留原出口 | 退出本插件的 NAT 处理，继续使用原有系统规则 |
| 使用 WAN 主地址 | 将匹配连接转换为选定的原生地址 |
| 按连接随机 | 新连接随机选择扩展池地址 |
| 按来源地址保持一致 | 对来源地址做固定种子的哈希映射 |
| 按 UDP 源端点保持一致 | 对来源地址和 UDP 来源端口做哈希，不将目的地址加入哈希 |

地址池不可用时，池策略按设置退回主地址或保留原出口。构建期间也应用回退策略。主地址或网络拓扑不可用时不能保证回退出网，页面显示等待或故障状态。

UDP 源端点方式固定的是源 IP 选择，不承诺 NAT 始终保留来源端口，也不改变防火墙放行策略。

主地址与扩展池分开；主地址不自动参加扩展池随机分配。保持一致的保证以池成员、顺序及映射参数不变为前提。单纯应用策略不清理 conntrack，不重新扫描地址池；地址重建、失效或主地址变化可能导致已有连接需要重连。

例外策略从上到下匹配，首条命中生效，支持来源类别、地址族、来源/目的 IP 或网段、TCP/UDP 及来源/目的端口或端口范围。未命中时使用该来源的默认策略。对 WAN 本地网段的访问始终排除在插件转换之外。暂不提供固定某个动态池地址的持久绑定。

代理集成默认关闭，须明确填写进程组 GID，匹配的是该组全部本机出站流量。代理重建连接后通常不能继续按原客户端区分。Tailscale 集成也默认关闭，其设备和来源范围均可配置；启用时按所有权维护 IPv6 源出口路由。IPv6 共享 `/64` 回程使用独立表 40960、优先级 32000；编号被其他规则占用时拒绝接管。

## 服务与权限

procd 分别托管 IPv4、IPv6 前台任务，合并接口事件并进行低频健康检查。每族持有独立锁，重复启动、重复应用和并发事件不产生第二个构建任务。故障使用受控重试，停止时终止构建并等待子任务退出后精确清理。

UCI 是持久配置来源；校验后的运行配置在内存文件系统中以不可变代次和原子指针发布。正在运行的任务保留自身引用的配置代次，错误配置不提交空服务实例。CLI 与 RPC 中的慢操作由后台任务执行。

服务需要管理地址、nftables 与路由，以 root 运行。RPC 仅提供状态、有限日志和固定动作；状态读取与配置/控制权限分别声明，不提供任意命令、路径或 nft 语句接口。日志使用 `sysu-snat` 标签；常规模式记录状态变化、构建摘要、故障和恢复，调试模式另记录批次进度。

### dnsmasq WAN 监听控制（1.0.0-r8）

“禁止 dnsmasq 监听地址池 WAN”默认开启。启用地址池前，插件为全部 dnsmasq 实例维护 `notinterface`，覆盖启用地址族的 WAN 逻辑接口和实际设备，避免 `bind-dynamic` 为数百个池地址创建大量 TCP/UDP 监听 socket。只有监听列表实际改变时才重载正在运行的 dnsmasq；不会启动原先停止的 DNS 服务。

插件以 dnsmasq 配置节中的 `sysu_snat_notinterface` 列表记录自身新增条目，随 DHCP 配置持久保存。已有条目不被认领；关闭此开关、停止全部地址池或卸载时，仅撤回插件拥有的条目，保留用户及其他服务的设置。接口切换期间，仍持有地址的旧设备继续保持限制，待地址释放后移除。保护范围随接口事件、DHCP 配置应用和周期检查更新。

关闭此开关表示由管理员自行管理 DNS 监听。应先确认监听已另行限定，避免在仍绑定大量池地址时恢复全接口监听。开关不会修改 DNS 上游、DHCP 地址池或 OpenClash 规则。WAN 与 LAN 共用同一实际设备时拒绝自动排除，以免一并切断 LAN DNS；DHCP 存在未应用修改时暂缓操作，避免提交其他人的设置；重载失败时恢复此前配置并阻止继续建池。错误会显示在页面和日志中。

隔离回归 `sh snat/tests/test-dns.sh` 在临时 UCI 目录中测试多实例、共享 WAN、重复执行、已有条目保留、开关撤回、接口变更、未应用修改、停止状态和重载失败回滚，不修改真实 DHCP 配置。

本次在实际路由器验证了开关关闭/开启，以及停止后撤回、启动前重新应用限制。既有 `wan/wan6` 排除项保留，插件只管理新增的实际设备条目；逐项比较确认其他 DHCP/DNS 选项未变。数百个池地址绑定时，dnsmasq 主进程使用 29 个文件描述符，软上限为 1024；LAN DNS A/AAAA 查询和双栈 HTTPS 均通过。

```sh
/etc/init.d/sysu-snat start     # 启动已启用的地址族
/etc/init.d/sysu-snat reload    # 校验并应用设置
/etc/init.d/sysu-snat stop      # 临时停止，保留 UCI 启用设置
/etc/init.d/sysu-snat rebuild   # 异步重新构建
logread -e sysu-snat
```

禁用并应用会取消自启动。仅使用“停止”或 CLI stop 表示临时停止。插件等待网络就绪，不启动或重启 SYSU Auth。

## 构建与验证

在 OpenWrt feed 中安装 `sysu-snat` 后可由 SDK 正常构建。也可在具有原生 APK 打包工具的 OpenWrt 25.12 构建环境中生成架构无关 APK 与 IPK：

```sh
python3 scripts/build-snat.py --sdk /path/to/openwrt
```

产物位于 `dist/snat`，附 SHA-256 清单。依赖 Lua、LuCI JSON 模块、ucode/UCI、ip-full、nftables、curl/CA 和基础工具，安装器由包管理器核对依赖。

离线检查：

```sh
lua5.1 snat/tests/test-netcalc.lua
lua5.1 snat/tests/test-netcalc6.lua
lua5.1 snat/tests/test-policy.lua
sh snat/tests/test-service.sh
node snat/tests/test-luci.cjs
```

具有 Lua `luci.jsonc` 和 `jsonfilter` 的环境还可运行以下隔离测试。它们用临时目录和模拟网络命令，不能证明真实地址分配权限或链路性能：

```sh
sh snat/tests/test-lifecycle4.sh
sh snat/tests/test-lifecycle6.sh
sh snat/tests/test-worker.sh
```

本次迁移在 OpenWrt 25.12.6 x86_64 上验证安装、默认禁用、配置和策略应用、地址池接管、实际双栈数据通路及 LuCI 页面。现场异常路径测试发现并修复了空实例提交、运行目录符号链接的配置代次保留问题，补充对应回归。现场曾因此重建地址池；地址数量由当次验证结果决定。

2026-11-03，最终版本 `1.0.0-r4` 实测停止后清理全部持有地址、NAT 表和路由，重新启动后形成 IPv4 242、IPv6 247 个可用地址。电脑发起的双栈 HTTPS 均返回 200，conntrack 确认两族都使用池地址；认证会话与受保护配置保持不变。重复应用、无效配置、非原生主地址及真实例外策略应用均验证保留任务和池记录；未登录的状态与控制请求均被拒绝。LuCI 实际页面和深色主题已检查。

没有通过重启整机验证开机启动，没有执行真实 sysupgrade；IPK 已构建，其真实安装与其他平台数据通路尚未验证。当前池拓扑要求 IPv4 私有 WAN、不与 LAN 重叠；IPv6 全球 `/64`、链路本地网关和 LAN ULA `/48`–`/64`。不宣称支持任意 PPPoE、PD、多 WAN、端口映射或固定动态池地址。

## 从旧版迁移

不要直接同时启用旧 cron/hotplug 与新服务。新服务检测到旧维护任务时拒绝启动。先备份实际安装的脚本、库、配置、任务、地址与路由状态，再校验并移交所有权，最后启用新服务。路由器中的源码副本和 GitHub 远端可能落后于实际安装版本。

本次现场备份位置由 `/root/sysu-snat-migration-path` 记录，恢复入口为 `/root/sysu-snat-rollback.sh`。回退会停止新服务，恢复旧维护方式并重新验证地址池，连接可能需要重连。配置及备份不写入 Git 仓库。

软件包管理实现文件，UCI 管理持久配置；固件升级后是否需要重新安装软件包，遵循 OpenWrt 的正常软件包保留方式。
