# SYSU SNAT v2 验收

日期：2026-11-07。目标：OpenWrt 25.12.6 x86_64。正式包：`sysu-snat-2.0.0-r15-x86_64.apk`。

## 交付结构

实现只包含单一 v2 控制器、两个 C 辅助程序、配置/DNS 管理与 LuCI。没有双 worker、Lua 引擎、兼容映射、迁移模型、接管/回退工具或对应依赖。运行配置只有 `policy.json`，host/endpoint 统一使用 1024 桶 rendezvous 映射。用户安装一个 `sysu-snat` 包即可使用全部功能。

实机 25 个程序文件与正式包逐项 SHA-256 校验一致；两族均 active、五个绑定、五个严格合格地址。APK SHA-256：`a15374350da7847312cc83f2fcab838f37ea0f75a25ac9fc8c2e95d56da1c84a`。

```sh
sh snat/tests/test-service.sh
node snat/tests/test-luci.cjs
python3 snat/v2/tests/live.py --router OpenWrt
```
